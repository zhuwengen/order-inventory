# 代码注释规范

编写或修改代码时，遵循以下注释要求：

1. 为关键业务规则、事务边界、并发控制、幂等处理、复杂 SQL 和异常处理添加简洁的中文注释，说明“为什么这样做”。
2. 为公开 API、DTO 中容易误解的字段或状态值添加必要注释。
3. 不为变量赋值、简单 getter/setter、显而易见的流程控制等重复代码本身含义的内容添加注释。
4. 保持注释与代码同步；修改行为时必须同步更新相关注释，删除失效注释。
5. 注释必须准确、简洁，并使用与项目现有代码一致的语言和风格。
